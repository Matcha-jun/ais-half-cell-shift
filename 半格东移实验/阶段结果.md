# 半格东移对照实验的阶段结果

在预先设定的主场景中，两期各有 200 艘模拟船，热点空间标准差为 3.5 km，格宽 10 km。以估计东移至少 5 km 为判据，**多起点取中位数的检出率为 85.95%，单网格为 50.06%**。真实热点不动时，两者的误报率分别为 0.00% 和 2.05%。

## 主场景

| 指标 | 单网格 | 16 起点中位数 | 配对差及近似 95% 区间 |
| --- | ---: | ---: | ---: |
| 零位移误报率 | 2.05% | 0.00% | −2.05 个百分点 [−2.29, −1.82] |
| 半格东移检出率 | 50.06% | 85.95% | +35.89 个百分点 [+34.58, +37.20] |
| 半格位移平均绝对误差 | 5.00 km | 1.46 km | −3.54 km [−3.64, −3.44] |
| 零位移平均绝对误差 | 0.40 km | 0.00 km | −0.40 km [−0.44, −0.37] |

检出率配对差的区间下限高于 0，误报率配对差的区间上限低于预设的 +2 个百分点，达到方案的改善判据。多起点在主场景的 2,000 轮零位移试验中出现 0 次误报。

## 两组对照解释了误差来源

- **只换划格就能制造半格位移。** 两期使用完全相同的船位，保持网格起点一致时，误报率为 0%。仅把第二期起点向东移 5 km，16 个起点等权汇总的误报率为 50.00%，达到东移判据的换格结果来自网格变更。这组结果与主表分别统计，主表的单网格在两期一直使用同一起点。
- **固定单网格也会把真实位移量化。** 同一起点下，两期最热格中心的东西向位移只能取 10 km 的整数倍，真实位移为 5 km 时，单网格每次的绝对误差至少是 5 km。无抽样波动的单点检查中，16 个网格起点各有 8 个给出 0 和 10 km，中位数给出 5 km。多起点汇总因此能在这个半格情形下表达单网格缺失的位移值。

## 样本量和热点集中程度的影响

| 场景 | 半格检出率，单网格 → 多起点 | 半格平均绝对误差，单网格 → 多起点 | 零位移误报率，单网格 → 多起点 |
| --- | ---: | ---: | ---: |
| 每期 50 艘 | 50.12% → 72.50% | 5.00 → 2.73 km | 4.13% → 0.00% |
| 每期 800 艘 | 49.88% → 91.10% | 5.00 → 0.81 km | 1.06% → 0.00% |
| 热点较集中，标准差 1.5 km | 50.07% → 95.55% | 5.00 → 0.46 km | 0.74% → 0.00% |
| 热点较分散，标准差 6.5 km | 50.13% → 63.55% | 5.00 → 3.70 km | 5.88% → 0.10% |

四组单因素补充场景中，多起点均提高了半格检出率。收益随配置变化，热点分散时仅增加 13.42 个百分点，仍有 36.45% 的真实半格东移未达到判据。报告可把主场景写成方法对照，把分散热点作为效果减弱的例子。试验覆盖单一高斯热点、固定格宽和半格东移，判据也设在半格处。

## 复现

在项目根目录运行 `python -X utf8 半格东移实验/模拟.py`。脚本使用 Python 和 NumPy，本次运行版本为 Python 3.14.6、NumPy 2.4.6。脚本会输出两期换格对照的误报率，并在自身目录中生成[汇总数据](汇总数据.csv)，包含全部场景的指标和轮级配对差区间。
